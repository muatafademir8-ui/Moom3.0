MOOM - PSP / PPSSPP  (7 bolum)

BOLUMLER
  1 ZINDAN  2 HASTANE  3 FABRIKA  4 DEPO  5 KANALIZASYON  6 LABORATUVAR  7 CATI KATI (son, 2 patron)

KONTROLLER
  Analog yukari/asagi : ileri / geri
  Analog sag/sol      : saga / sola don (Doom gibi sadece yatay bakis)
  D-pad               : hareket + don (alternatif)
  L / R               : sola / saga yan yurume
  Daire (basili)      : kosma
  X veya Kare         : pompali tufek ates
  START               : bolum bitince sonraki bolum, olunce bolumu bastan baslat

OYUN
  - Zombiler (yesil) yakin dovusur, iblisler (kirmizi, boynuzlu) uzaktan ates eder.
  - Patron (mor, buyuk) cok can ve guclu ates; oldurunce +12 mermi.
  - Her oldurmede +5 mermi. Haritada saglik ve mermi kutulari var.
  - Bolumdeki herkesi oldurunce bolum biter (+30 can, +12 mermi bonusu).

DERLEME
  main.c ve Makefile'i PSP projenin klasorune koy (eskilerin yerine),
  GitHub Actions ayni sekilde EBOOT.PBP uretir.
